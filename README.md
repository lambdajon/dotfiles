# dotfiles

## Hosts

All hosts run NixOS 26.05 with Home Manager embedded.




## Usage

Enter the dev shell for formatting and linting tools:

```sh
nix develop
```

Common `just` recipes:

```sh
just check            # nix flake check
just format           # nix fmt
just switch-victus    # nixos-rebuild switch for victus
just switch-tower     # nixos-rebuild switch for tower
just switch-vicub     # nixos-rebuild switch for vicub
just eval-victus      # dry eval (no build)
just disk-victus      # partition + format + mount (destructive!)
just disk-tower       # partition + format + mount (destructive!)
just disk-vicub       # partition + format + mount (destructive!)
just install-victus   # disk-victus then nixos-install (full fresh install)
just install-tower    # disk-tower then nixos-install (full fresh install)
just install-vicub    # disk-vicub then nixos-install (full fresh install)
```

## Adding a new host

1. Create `hosts/<name>/default.nix` and `hosts/<name>/hardware-configuration.nix` (generated by `nixos-generate-config`).
2. Optionally add `hosts/<name>/disk.nix` for disko partitioning.
3. Register it in `flake.nix` under `nixosConfigurations`.
4. Add `switch-<name>` and `eval-<name>` recipes to `justfile`.
